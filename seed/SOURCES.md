# The founding collection

Texts shelved by the library itself on first start (see `shelveSeeds` in `db.js`). Each is shelved once, under the first librarian's wallet; later edits or deletions by a librarian are never undone. `index.json` holds the catalogue details and the "why read this" notes.

Editors' introductions, footnotes and endnotes from the source editions are left out. Tables are flattened to lines of text.
